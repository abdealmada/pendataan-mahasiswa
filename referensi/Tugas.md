1. DESKRIPSI PROYEK
Mahasiswa diwajibkan membangun sebuah aplikasi web dinamis berjudul "Sistem
Manajemen Data Interaktif" yang mengintegrasikan seluruh materi pembelajaran dari
Pertemuan 1 hingga Pertemuan 7. Mahasiswa dipersilakan memilih salah satu tema proyek
di bawah ini:
Manajemen Data Mahasiswa (Input, edit, & daftar data mahasiswa)
2. KETENTUAN TEKNIS APLIKASI
a. Struktur Dokumen: Wajib menggunakan HTML5 Semantik secara konsisten
(<header>, <nav>, <main>, <section>, <article>, <footer>).
b. Tata Letak (Layouting): Wajib menggunakan CSS Modern (Flexbox atau CSS Grid)
tanpa menggunakan framework CSS eksternal.
c. Responsivitas: Wajib menerapkan pendekatan Mobile-First Design (diuji dan tampil
proporsional pada layar smartphone maupun desktop).
d. Interaktivitas (Client-Side): Wajib menggunakan JavaScript untuk minimal 1 (satu)
fitur interaktif, seperti validasi form real-time, manipulasi DOM, atau toggle tema.
e. Pemrosesan Server (Backend): Wajib menggunakan PHP untuk menangani Form
Data (metode GET dan POST) serta pemrosesan data sederhana (menampilkan kembali
data yang diinputkan).
3. KETENTUAN DOKUMENTASI DAN LAPORAN
Setiap mahasiswa wajib menyusun dokumen laporan proyek dengan ketentuan struktur
sebagai berikut:
a. Struktur Folder: Wajib membuat folder bernama docs/ di dalam repositori GitHub.
b. File Laporan: Berkas laporan diberi judul "Laporan Project [Nama Mahasiswa]".
c. Format Dokumen: Format kertas A4, font Times New Roman 12pt, dengan spasi 1,5.
d. Sistematika Isi Laporan:
• Identitas Lengkap (Nama, NIM, Kelas, Mata Kuliah).
• Analisis Kebutuhan Sistem (Deskripsi singkat, tujuan, dan alur pengguna).
• Dokumentasi Visual (Screenshot tampilan antarmuka versi Mobile & Desktop).
• Penjelasan Struktur Kode & Alur Data (Penjelasan HTML, CSS, JavaScript, dan
alur PHP).
• URL Github
4. PROSEDUR PENGUMPULAN
a. Repositori GitHub: Unggah seluruh kode program dan folder docs/ ke repositori
GitHub (publik/privat).
b. Pengumpulan Link: Kumpulkan Dokumen jawaban melalui edlink.
